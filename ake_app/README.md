# AKE Forging App

اپلیکیشن Flutter آریان کوب اسپادانا (AKE Forging) با رابط فارسی و راست‌چین.

## مستندات ضروری پروژه
قبل از هر ویرایش یا رفع اشکال، این فایل‌ها را به‌ترتیب بررسی کنید:

- [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) — وضعیت پروژه، ساختار فایل‌ها، محیط توسعه و قابلیت‌های موجود.
- [TROUBLESHOOTING.md](TROUBLESHOOTING.md) — خطاهای قبلی، مسیرهای ناموفق و راهکارهای تأییدشده.
- [CHANGELOG.md](CHANGELOG.md) — تاریخچه تغییرات و تست‌ها.

## اجرای پروژه
از پوشه `ake_app` در CMD:

```cmd
flutter pub get
flutter run
```

در صورت خطای دانلود وابستگی‌ها، قبل از پاک‌کردن cache یا تغییر نسخه ابزارها، ابتدا بخش مربوط در `TROUBLESHOOTING.md` را بخوانید.

## مشخصات طراحی
- رابط فارسی و RTL
- رنگ اصلی: `#01ADA5`
- رنگ مکمل: `#57595B`

## قانون نگهداری پروژه
هر تغییر کد باید با به‌روزرسانی مستندات مربوط همراه باشد. هر خطا و هر راهکار ناموفق یا موفق در `TROUBLESHOOTING.md` ثبت شود تا دوباره آزمون‌وخطای تکراری انجام نشود. امکاناتی که فقط در رابط کاربری پیاده‌سازی شده‌اند، تا زمان اتصال و تست واقعی به‌عنوان قابلیت عملیاتی معرفی نشوند.

## ساخت اندروید با نقشه نشان
این پروژه از neshan_maps_flutter استفاده می‌کند که در اندروید نقشه را داخل WebView و با SDK وب نشان نمایش می‌دهد. بنابراین کلید لازم حتماً باید از نوع **Web** باشد؛ کلیدهای Mobile/Android کار نمی‌کنند. محدودیت دامنه/IP را برای این کلید فعال نکنید و سرویس نقشه پایه وب (ترجیحاً Vector) را در پنل نشان فعال کنید.

```cmd
flutter pub get
flutter build apk --release --target-platform android-arm64
```

پس از نصب APK، هنگام انتخاب موقعیت تحویل، کلید Web را در صفحه تنظیم نقشه وارد کنید. کلید به‌صورت امن روی همان گوشی ذخیره می‌شود و نیازی به قرار دادن آن در کد، GitHub یا دستور build نیست.
## افزونه مکمل وردپرس
فایل wordpress/ake-delivery.php نسخه 0.2.0 افزونه AKE Delivery API است. این نسخه شناسه کاربر را در پاسخ موفق ثبت‌نام Digits به REST API اضافه می‌کند، سفارش‌های دارای محصول ساده و وارییشن معتبر را می‌پذیرد و API مأموریت پیک و تغییر وضعیت تحویل را ارائه می‌کند.

برای نصب، ابتدا از فایل فعلی wp-content/plugins/ake mokamel/ake-delivery.php نسخه پشتیبان بگیرید، سپس فایل جدید را دقیقاً جایگزین همان فایل کنید. فایل‌های خود Digits را ویرایش نکنید. پس از جایگزینی، در فهرست افزونه‌ها نسخه 0.2.0 را بررسی کنید.

**محدودیت استقرار:** اتصال فعلی WPVibe روی این سایت امکان خواندن فایل‌های افزونه را دارد اما نوشتن مستقیم در پوشه افزونه‌ها را پشتیبانی نمی‌کند؛ بنابراین جایگزینی فایل PHP باید توسط مدیر سایت از File Manager هاست یا FTP انجام شود.
